# Phase 1案 — 探索の土台

状態: Phase 1完了（2026-10-02、Notion正本でユーザー実機確認済み）。Phase 2の状態はphase-2-verification.mdを参照。以下の提案と記録はPhase 1の履歴。

## 目的と範囲

画面より広い古代日本風フィールドを歩き、地形によって移動経路が変わる探索の土台を確認する。
仕様にPhaseの定義はないため、この区分は実装上の提案であり、仕様決定ではない。

Phase 1に含めるもの:

- プレイヤーの8方向移動。CharacterBody2Dと衝突形状を使用し、斜め移動速度を正規化する。
- 矢印キーとWASDのInput Map。速度は試遊用の調整値とする。
- Camera2Dの追従とマップ境界での制限。
- 固定マップ1枚。外周、通行できない木・岩・川、通行できる橋を用意する。
- 草地、道、川、木、岩と古代日本風キャラクターのオリジナル仮ドット素材。
- 方向表示と簡単な歩行アニメーション。素材を変更できる小さいシーン構成。

敵、投剣、HP、EXP、レベルアップ、目的アイテムのランダム配置、ラウンド遷移は今回の範囲外。
Phase 2は未着手。Phase 1の実装・検証とユーザー確認が終わるまで次のPhaseに進めない。

- Phase 1では16pxタイル、32pxキャラクター、128×96タイルのフィールド、移動速度100px/秒を試す案。正式値は未決定。
- 地形は固定制作とする案。自動生成やGame 001からの全面コピーはしない。
- 主人公の正式設定、パレット、素材サイズは仕様上未決定。仮素材を最終品質として扱わない。

## Phase 1受け入れ基準

- 起動時のエラーがなく、マップとプレイヤーが表示される。
- WASD／矢印で8方向へ移動でき、斜めと直線の速度が同じになる。
- 壁・木・岩・川をすり抜けず、橋から川を渡れる。外周から出られない。
- カメラが追従し、四隅でもマップ外を表示しない。
- 画面より広いフィールドで、障害物を迂回する複数の経路を歩ける。
- ドット表示と歩行方向が判別でき、仕様の情報量・配色目標に対する不足を記録する。
- 検証結果とユーザー確認がそろうまではPhase 1を完了扱いにしない。

## Phase 1実装結果 — 2026-10-02

初期案から変更し、1536×1152の固定マップと20×24px程度の人物を実装。TileMapLayer／AnimatedSprite2Dの代わりにGDScriptの整数座標によるオリジナルドット描画を使用した。木・岩・川・祠と外周にはStaticBody2D、人物の足元にはCharacterBody2Dの衝突形状を配置。最低限の探索動作を優先したもので、正式素材・正式サイズの決定ではない。

8方向移動、WASD／矢印、100px/秒での速度正規化、カメラ追従、障害物とマップ境界を実装し、Godot実行による検証に成功した。詳細は[検証記録](phase-1-verification.md)を参照。Phase 1の実機確認を待ち、Phase 2には進まない。
